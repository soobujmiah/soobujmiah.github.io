My background also includes industrial site work, electrical installation and maintenance, coordination, computer operations, office administration and digital communications. 02MOBILE WORKSTATION ENGINEERINGANDROID IS PART OF THE WORKBENCH

A REAL BUILD–TEST–LEARN LOOP

The phone is a workstation, not just a screen.

My primary development environment is an Android phone running native Termux and Debian through PRoot. I plan, research, write and edit code, use Git and project tooling, inspect logs, debug issues, manage changes and maintain technical notes there.

  1. 01

    Plan the change and record constraints on the phone.

  2. 02

    Edit source and work with native Android, Termux and Linux tools.

  3. 03

    Use Git and repeatable scripts; send compute-heavy builds to GitHub Actions when appropriate.

  4. 04

    Return the artifact to the phone, install it and test against physical Android hardware.

  5. 05

    Debug, verify the result and record what should guide the next iteration.

The boundary matters: the phone is where much of my development and device validation happens; GitHub Actions is remote infrastructure for configured builds. I do not describe a remote build as on-device compilation.

05HOW I WORKEVIDENCE BEFORE CERTAINTY

FIELD NOTES → SYSTEMS → LIVING KNOWLEDGE

Make useful work understandable to the next person.

I treat documentation as part of the engineering work. Decisions should stay connected to their reasons, technical claims to their evidence, and failures to the next experiment.

  • Keep implemented, experimental, planned and unknown states distinct.
  • Test on the target device when desktop builds cannot establish real behavior.
  • Prefer repeatable steps and clear records over claims that cannot be reproduced.
  • Treat user consent, scope and safe failure as design requirements for automation.

Living Knowledge is a working philosophy: source, evidence, decisions and lessons can improve together over time. It is not a claim that every project or knowledge system is already complete.

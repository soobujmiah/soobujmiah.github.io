★ Flagship

Termux AI Workstation

A complete GPU-accelerated Linux desktop and local LLM inference lab running entirely on an Android phone — no PC, no root, no cloud. Built from scratch through independent research and documented end-to-end — every command, driver flag and failure mode covered in a technical guide.

Desktop Layer

PRoot Debian with Xfce4 over Termux-X11, D-Bus system daemon, PulseAudio routed via TCP to bypass Android background-audio limits, and automated x.sh launcher scripts.

Graphics Pipeline

Mesa Turnip + Zink translating OpenGL over native Vulkan on Adreno 825, with Freedreno drivers, shader disk caching and compositing tuned off for throughput.

AI Runtime

llama.cpp compiled with the Vulkan backend for full GPU offload, serving Llama 3.2, Qwen 2.5 and DeepSeek-R1 GGUF models locally over HTTP.

Agent Workflow

Claude Code, Hermes and OpenCode wired into the environment for autonomous development, plus zsh aliases and monitoring functions for one-touch operation.
